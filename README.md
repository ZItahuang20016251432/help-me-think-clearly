# Help Me Think Clearly · 帮我想清楚

遇到两难的选择，你可能已经听过两边的道理，真正拿不准的是哪一条更适合眼前的自己。这个 Codex Skill 让几种有分歧的观点围绕同一件事交锋，再把讨论落到三个问题上：**现在怎么选？先验证什么？看到什么结果值得改主意？**

## 试着问一次

> `$help-me-think-clearly` 我收到一份新工作邀请，薪水高一些，但每周要多通勤六小时，我也舍不得手里刚有起色的项目。请让贝佐斯、张爱玲和芒格讨论。在接受之前，我最值得向对方问清哪件事？

贝佐斯的视角会把时间拉长，问几年后更可能遗憾错过什么。张爱玲的视角会把这六小时放回日常，追问哪顿饭、哪次见面、哪段独处会先被挤掉。芒格的视角则会反过来问：假如三个月后就后悔，当初最可能漏算了哪笔账？带着这个分歧，你可以回去问清楚远程安排，也可以先在高峰期实走一次通勤路线。

## 安装到 Codex

复制当前仓库的网址，把下面这句话发给 Codex：

> 请从【粘贴仓库网址】安装 `skills/help-me-think-clearly` 到我的个人 Codex skills 目录，并检查安装结果。

安装后，在 Codex 输入 `$help-me-think-clearly`，再写下你的问题。可以点名，也可以让它根据问题选人。如果已经安装过，下次想用新版时，让 Codex 从同一位置更新即可。

## 什么时候用

| 正在犹豫的事 | 可以请谁讨论 |
| --- | --- |
| 这份合作值得占用未来半年的时间吗？ | 巴菲特看机会成本，乔布斯看它会挤掉哪件最重要的事。 |
| 答应家人的事已经影响到自己的生活，还能重新谈吗？ | 孔子看承诺与责任，张爱玲看双方各自承担的日常代价。 |
| 一个项目连续失败，还值得再试一次吗？ | 马斯克追问下次试验能学到什么，卡尼曼检查你是否被已经付出的成本牵着走。 |

共有 81 位人物，涵盖人生选择、资金分配、创业、产品、技术、增长、科学、战略、团队以及风险。输入 `$help-me-think-clearly roster` 可查看名单。日常小选择可加 `quick`；想深入听反对意见可用 `deep`。讨论中也可以补充新事实，再问“谁会因此改变判断，为什么？”

讨论中的人物发言是根据公开作品与资料生成的模拟分析。人物资料与决策流程见 [Skill 目录](skills/help-me-think-clearly/)，许可见 [MIT License](LICENSE)。
